Módulo de Uso Offline

Prepare seu celular ou tablet para operar 100% sem internet nas áreas de produção.

Por que ficou desconfigurado antes?

O navegador do celular precisa de todas as bibliotecas de estilos (Tailwind) e scripts (PapaParse, html2pdf, xlsx) para desenhar o aplicativo. Quando você baixa apenas o arquivo HTML comum, o celular tenta buscar esses arquivos e não os encontra, quebrando todo o design.

A Solução Definitiva:

Nosso compilador junta todos esses arquivos e estilos em um ÚNICO arquivo HTML integrado. Você só precisa baixar esse arquivo único. Ele funcionará perfeitamente offline!

📱

Como enviar e usar no aparelho

Siga o passo a passo abaixo para levar o aplicativo para o tablet ou celular de campo:

📥 Passo 1: Transferir
  • Clique no botão verde acima para baixar o arquivo integrado.
  • Envie o arquivo baixado para o tablet/celular (pode enviar pelo WhatsApp, e-mail ou cabo USB).
  • No celular, abra o arquivo utilizando o navegador de internet (Chrome no Android, Safari no iOS).
🤖 Passo 2: No Android (Chrome)
  1. Abra o arquivo no Google Chrome.
  2. Toque nos três pontinhos (⋮) no canto superior direito.
  3. Selecione "Adicionar à tela inicial" ou "Instalar aplicativo".
🍏 Passo 2: No iOS / iPad (Safari)
  1. Abra o arquivo no Safari.
  2. Toque no botão de Compartilhar 📤.
  3. Role a lista e toque em "Adicionar à Tela de Início".
